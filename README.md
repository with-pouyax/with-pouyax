## Hi, I'm Pouya

I build software at the intersection of **data, enterprise applications, automation, and systems engineering**. I work in Digital & Data at Takeda in Vienna and completed the **42 Vienna Common Core** in September 2026.

My professional work includes Power Platform applications, operational analytics, approval workflows, and integrations. The public repositories below show the parts of my engineering work that can be shared openly. My employer's internal code and data are not included.
